# Reto de Recolección

Videojuego 3D en primera persona desarrollado con Unity.

## Objetivo
Recolectar los 10 cubos amarillos, evitar la esfera roja y completar el desafío antes de que termine el tiempo.

## Controles
- Teclado: movimiento del jugador.
- Mouse: control de la cámara.

## Plataforma
Windows.

## Ejecución
Descargar el archivo ZIP del juego desde la sección Releases, descomprimirlo y ejecutar `My project (1).exe`.
